# Code Simplifier

当任务目标是“在不改变行为的前提下简化、重构、标准化代码”时使用这个 skill。

## 目标

提升代码清晰度、一致性、可维护性，同时保持原有功能和输出不变。

## 执行规则

- 不改变业务行为
- 遵循当前工作区的 `AGENTS.md`、项目规范和本地约定
- 优先复用项目已有公共工具、基础库和既有抽象
- 以可读性优先，不为了少几行代码牺牲清晰度
- 去掉重复代码和无效嵌套
- 不修改生成文件、锁文件或外部产物，除非任务明确要求
- 沟通语言和代码注释语言遵循当前项目约定

## 关注范围

- 优先处理当前任务刚修改过的文件
- 除非为了保证一致性，不主动扩大重构范围
- 在脏工作区中只处理任务相关文件，避免覆盖用户已有改动

## 常见检查项

- 重复的转换逻辑
- 重复的数据访问或 API 调用模式
- 不必要的包装层
- 职责混杂、过长的函数
- 命名不清晰
- 死代码、过期入口和无效 fallback
- 缺失或不足的回归测试
