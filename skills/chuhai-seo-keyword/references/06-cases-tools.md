# 06 案例规律、避坑清单与工具箱

> 精读 `H_cases.md`、`G_tools.md`（各 Top45 篇）全文，筛查 `rule_bank.md` 含「不要/建议/误区/教训」的 352 条规则句（20 类），回查点名案例。资料跨 2024-07~2026-10，冲突以新为准。

## 一、案例库（16 个样本）

**1. [id=28]《以月收入$50k的网站为例》（20250120）｜游戏站·大词**
`sprunkin.com` 晚 20 天（10/17）注册域名，靠外链（878 引荐域）、上游戏内页（收录 1330 页）、游戏放自家 CDN 让人 `iframe` 引用反吃点击。流量 3 万→127 万→12 月 304 万→近 28 天 365 万；推算 12 月收入约 $40K，原第一 `Sprunki.org` 约 $120K（当年靠 600+ 外链拿第一和 Sitelinks）。规律：**大词哪怕迟到、KD 六七十，只要竞争页是弱鸡，持续加外链+内页仍能后来居上**。

**2. [id=227]《新词新站赛开榜 冠军10天140万UV》（20260922）｜比赛复盘**
冠军 10 天 140 万 UV；亚军包揽第二、第四，第二名 64 万 UV/1700 万 PV；域名均为 7/20–8/31 注册。哥飞自曝自家站拿 `AI Video Generator` 流量外链投入约 $12K，称「低竞争词才可能靠免费外链，高竞争词在榜玩家都在买外链」。规律：赛期拼「找到大词+抓窗口+搞流量」；单条外链无法归因，只看一段时间内多外链综合效果。

**3. [id=212]《游戏站两天百万UV，数据服务正式上线》（20261011）｜游戏站**
两天约百万访问、单日 60 万点击、点击率约 30%；按 Adsterra 粗估收入至少 $3500。玩法是第二名站与第四名辅助站互相导流、参赛站集体向第二名导流（id=227）。规律：爆量游戏站靠导流矩阵+广告位密度变现，Cloudflare 免费档扛不住；排名稳后「当前文案不要动，只加游戏列表」。

**4. [id=216]《新站首日靠 ChatGPT 流量入账 221 美元》（20260930）｜AI 视频站**
昨晚 23 点上线，首日 600 UV/1400 PV/255 注册/17 单/$221，零外链零广告，付费用户全来自 ChatGPT。打法：**老站内页测新词→观察搜索与 AI 推荐流量→有付费就单独建站全力推**；做「带功能的落地页」，给一两次免费使用、付费时跳主站。规律：ChatGPT 更看页面是否完整解决任务，精准域名不具决定性。

**5. [id=236]《AI视频站首日过千刀》＋[id=226]｜AI 视频站**
首日 $221 当晚破千刀，一周破 $4000，流量成本为零；成本仅 API 约 $200+域名 $160。ChatGPT 渠道 282 访客中 172 注册（61%）、付费率 6.4%，外链只加六七条，排名靠竞争少的小词，TrustMRR 验收入。规律：让 Claude 用 API key 跑视频自行对比选型（seeapi 的 seedance 2.0），不只看参数（id=212）。

**6. [id=140]《国庆上站大行动：4个月6站零收入→一天4站日破千刀超100单》（20261008）｜批量上站**
A/B/C/D 四站 UV 300+/40+/600+/100+，付费 20/2/56/4，注册付费转化率约 32%/6.7%/12%/13%，总出单超 100、单站最多 70+。规律：「别多想，就是干」「雨露均沾」——不押注单词、不因大量域名已被注册就放弃（很多人只注册不做站）、复用模板快速上线。

**7. [id=911]《新手复盘：4个月赚到1刀，15天破1000刀》（20250926）｜工具/订阅站**
前 3 月 10 站零收入；转折是用 Similarweb 查 `huggingface.co`「着陆页」找上升内页，挖到新词 `italian brainrot`（X 大 V 发的词，Trends 量约 GPTs 的 1/5），$2 注册 `.art` 域名几小时上线；上线第二天出单、第五天 $327 年订阅、14 天破千刀。踩坑：上线多语言后核心词被搜不到（`/ja` 与 `/ja/` 重复页），改 canonical+几十条外链一周后恢复。规律：先跑通「找词→上站→GSC/GA→收款」闭环。

**8. [id=235]《EMD打新词踩坑》（20260916）｜EMD 批量注册反面**
ZENGYUN 用 EMD 打 `gpt image 2.5`，五天后才在第六页找到 EMD 站，**30 个 EMD 站也没混上主词排名**——该词不是独立新需求而是旧主题变体，且被同名公司污染。哥飞：`.com` 被抢时选精确词非 .com 还是同义词 .com，看变体优化难度；各家平台算法不同、谷歌不公布真实算法，**搞 SEO 不要对数字太敏感**。

**9. [id=319]《站内优化、多语言、外链等因素》（20250115）｜「同一个关键词的三个站」**
`that's not my neighbor`：`thatsnot-myneighbor.io`（DR59、外链域 1400、977 页）、`thatsnotmyneighbor.org`（DR58、1400 域、758 页）、`.online`（DR30、131 域、仅 2 页却流量最高）、8 月才注册的 `thatsnotmy-neighbor.io`（DR39、645 域、210 页）。哥飞点破的隐蔽共同点：**三站不管横向加多少游戏内页，首页第一屏永远保留域名关键词那个游戏，根基不能丢**；AI 工具站横向扩展同理（rule_bank id=0/46/64/284）。同文 `pokerogue.cc`：5/1 注册专打 5 月新词赛，在前三名（各 200+ 反链、Similarweb KD 仅 4）围堵下仍拿 28 天 40 万点击、巅峰日 2 万+，靠韩语页在韩国排名第 2、点击率 45%+、词密度 3.76%。

**10. [id=455]《一个站长的多个网站流量分析》（20251013）｜站群/数据类**
`texteditor.com` 326K、`textfancy.com` 53.6K、`textpaint.com` 3.9K、`textstyler.com` 1.2K、`textheads.com` 近零。规律：「有搜索量的关键词，一词一站」是十几年前就有的老玩法；重点学其选品与外链策略。

**11. [id=523]《案例拆解 distance.to》（20251103）｜数据类/PSEO**
谷歌收录 129 万页，服务器里却没有 129 万个 HTML——统一模板+数据库取两地坐标算距离动态渲染。规律：盯住「两地距离」这种小需求也能做百万月访问，因为**可生成海量页面、单页几个访问聚沙成塔**；先规划数据结构再找公开数据源爬取（有版权数据不要抓）；新站多语言用子目录冷启动成本更低（id=66/476）。

**12. [id=1091]《5月新词比赛第五名复盘》（20260615）｜比赛复盘**
前 3 站全败（偏品牌词域名、Semrush 筛 KD 找的小语种词「需求太杂」、做的偏晚+体验差），第 4 站获奖且「大部分拿结果的群友做的都是这个词」。教训：KD 只是辅助，真正要看 SERP 结构和用户意图；工具站用户试一次不好就不再回来；多 Agent 协作产出差。**看到新词可以直接上，失败就是一个域名钱**。

**13. [id=1064]《5月份新词第4名复盘》（20260613）｜比赛复盘/数据化**
一年做 30+ 站（AdSense+Adsterra 每天几十刀，不稳定）。方法：给 similarweb.com 写插件封装成 API（取关键词、竞品落地页、外链），让 Codex 自动请求分析；自定义 SKILL 规范页面（关键词簇不跑题、禁纯 JS 渲染、检查 TDK/H）。教训：「找对词却没流量」根因常是页面写得不够好；**不能轻信 AI 的版权保守建议**——照 Codex 把动漫人物换成色块导致跳出率极高，无视提示复刻原版后该内页承担 80% 流量。

**14. [id=1066]《Sinan：1月新词比赛获奖经验教训》（20260215）｜老词/成本**
专挑「高 KD 但搜索量极大、长尾多、有软柿子（排名靠前但移动端烂到没法用）」的老词，做 3-4 个站才有一个起量；2 个站因页面质量不高被 K，换域名几天后又被 K。成本教训：**Vercel 动态生成上万页会被套餐限额和带宽打爆（爬虫就能耗光），月成本几十上百刀；Cloudflare 月费 $5 起、带宽免费，每月省上百刀**。

**15. [id=1082]《月收入从$3000涨到$9600，差点玩没支付账户》（20260731）｜收款**
7/18 一个 Stripe 账号下 2 个子账号被关（大概率因同一子账号建了多个网站收款），找代理要 $4000–10000；靠群友办法两天用 Wise 开了英国 Stripe。规律：**支付通道必须多样化**；产品体验做好前不要过早优化漏斗——搞一周站内登录/多通道/支付宝/品牌 icon，失败率反而更高。

**16. [id=207]《ForgeGUI 调研报告》（20260825）｜非 SEO 打法**
2026/3/12 上线，18 岁创始人，种子轮 $320 万、估值 $4000 万；用户数（自述）6/21 9 万→7/28 30 万→8 月 56 万+；**Ahrefs 显示 SEO 流量仅约 240/月且几乎全是品牌词**。规律：不靠 SEO 不靠投放，靠 Roblox 开发者圈 YouTuber 带货+论坛铺帖+免费积分裂变，切入「游戏缩略图决定 CTR」这个可量化付费痛点。并非所有案例都是 SEO 案例，别硬套。

**补充**：[id=1001] 工具站别开 AdSense 自动广告（误触），广告位手动放、用 `utm_*`+GA 定位异常渠道；[id=224] `birthdayfreebies.com` 2003 精准域名、月搜十几万仍无排名（SPA 空壳、URL 全数字、TDK 不围绕主词、DR 9），**老域名≠有权重**；[id=950] PNG 部落 0 编程基础 1 月变现 5K+；内容站见 [id=1039] 游戏攻略站（AI 写文、搜「游戏名 codes」）。「20天480万访问/俄罗斯版妙鸭相机」仅作参考链接引用（id=77 附近），未展开数据。

## 二、避坑清单（26 条，标来源 id）

1. 新站第一周不要铺 3000 页，新内容慢慢放，别一上来几十万页（id=57、68、293）。
2. 别盲目批量上页面/追大词，否则大词低排名低点击拉低整体 CTR，连累小词（id=421、297、395）。
3. 新站不要一上来铺太多语言（重要的事说三遍），先跑通核心语言的收录与体验（id=1084）。
4. 多语言优先子目录；只翻界面没翻主体内容时别做子目录多语言，全部 canonical 指向默认语言（id=66、476、533）。
5. 多语言配置（地区码、x-default、canonical）封装成公共组件统一生成，别每页手写（id=1084）。
6. 上线多语言前排查 `/ja` 与 `/ja/`、http/https 并存等重复 URL，易被判重复页处罚（id=911、476）。
7. 一页只放一个 H1、只写一种语言、一关键词一页面；别同页同时放大词和小词（id=99、297、533）。
8. 关键词密度 3%–5%，千万别太高；忌让无关内容冲淡核心词密度（id=423、284、346）。
9. UGC/评论区内容不要混进落地页，会稀释核心词密度（id=28）。
10. 已上线很久、有稳定流量的页面别随便大改；改版第一原则是已存在的 URL 一个都别动（id=998、103、38）。
11. on-page 调整完别天天改，排名波动正常，耐心等 1–2 周（id=340、735）。
12. 排名未稳的头 1–4 周不要改 TDH（id=106）。
13. 页面必须后端渲染或至少写好 Headings；纯前端 SPA 谷歌只拿到空 HTML 模板，无法排名（id=28、358）。
14. 别买几十几百元几千条外链，别碰 PBN/论坛签名/Fiverr 千条/Ahrefs 标 Spam 的站，整站降权几年翻不了身（id=695、932、110）。
15. 外链初期数量优先但守底线：100 个一般域名好于 1 个高权重域名，只找 Ahrefs `Best Links`，Spam 绝对不碰（id=932）。
16. 别觉得 nofollow、博客评论外链没用，「你觉得没用就是量不够」；但别一上来用工具把速度拉满（id=695、298、221）。
17. 外链类型要杂、锚文本及邻近词不能一段文本一直用，符合自然增长（id=197、221）。
18. 别只看单个工具数据下结论：Ahrefs 摸 SEO、Similarweb 摸全渠道、插件又一口径，必须交叉验证（id=797）。
19. 找竞品必须从目标词 SERP 反查，不能猜域名（id=187）。
20. 找词别和别人对比、别对 KD/搜索量数字太敏感，KD 与收益不一定正相关（id=211、235）。
21. 别迷信自动化：新手先像素级手动摸熟全流程，「什么都不会时别搞自动化」（id=813、1094、204）。
22. 不要焦虑式买工具和数据，「工具是赚钱之后的，不是有了工具就能赚钱」（id=214）。
23. 别用办公司、研究工具、优化代码代替业务进展；产品没开发前别浪费时间注册海外公司（id=1084、340）。
24. 别一上线就申请 AdSense，等有流量再申请；账号要隔离，新 Gmail 先养半个月（id=340、243、247）。
25. 工具站别开 AdSense 自动广告，广告位手动放、移动端 PC 分别查（id=1001）。
26. 一个 Ads 账号只投一个网站；千万别不设最高点击出价；别采纳系统「加预算」建议（id=744、745、750）；支付侧一个身份资料别注册多个 Stripe 账号、多站别共用一个商户（id=73、211）。

## 三、工具箱（用途／免费付费／取舍）

**找词拓展**：Google 下拉/相关搜索、各平台搜索框下拉、**Google Ads 关键词规划工具**（免费，「发现新关键词」+「获取搜索量和预测数据」，最准，Similarweb/Semrush 的量也源自它）、Google Trends（相对趋势，加双引号辨同义词真实热度，id=77）、Ahrefs Keyword Generator 免费版、keywordtool.io。付费：Semrush `Keyword Magic Tool`（筛 volume≥30000 / KD≤60 / CPC≥0.01，id=1037、792）、Similarweb 关键词研究/着陆页。共享账号淘宝可买（id=733），但共享账号不能走 API（id=232）。

**看趋势**：Google Trends；`seo.web.cafe/trends`（SEO Agent 插件/网页版，每天赠 50 次积分、可 API，id=236）；`new.web.cafe/data` 数据服务（2026-09 起，100 元/月、每月降 10 元、10 个月后免费，新人赠 100 天，含新词/新站/网站发现，将开放 API+Webhook，id=212、226）；Product Hunt、X、GitHub、Reddit、HN 追热点（id=596、239）。

**查竞品/盘面**：Similarweb（全渠道流量、地域、跳出率、停留时长、相似站，免登录可看基础数据）、Semrush（SEO 流量、KD、按国家分布、出入站外链；一次只看一国、要切 PC/移动端）、Ahrefs（DR/KD/外链/`Best Links`/`Spam`）、AITDK.com 插件（免费，看 TDH、Canonical、robots.txt、sitemap、词数、H1 数，**每个内页都能分析**，id=214）、Google Organic SERP CTR Curve、KGR 公式 `intitle 结果数÷月搜索量`（id=792）。**取舍口诀：Ahrefs 摸 SEO、Similarweb 摸全渠道、Semrush 看关键词，三家绝对值都不信时信谷歌**（id=797、77）；免费版已覆盖 90% 需求（id=982）。

**查外链**：Ahrefs Backlink Checker / Semrush 导出；哥飞外链价值计算器；Backlink Helper 插件（免费 50 条库，自带 Gemini/OpenRouter/硅基流动 Key，id=938）；Claude Code+Playwright MCP 批量提交（3 天 300+，id=868）；AdsPower Local API+2Captcha 过验证码（id=201）；维基百科死链替换法（id=231）。

**看排名/数据**：GSC（必做第一步，DNS 验证、请求编入索引、看收录/出词/排名/CTR）、GA4（自定义维度必须**上线当天注册，不回填**，id=178）、Plausible（哥飞偏爱，可 VPS 自部署）、Bing Webmaster、GSC 数据模拟器（id=932）、TrustMRR（挂 Stripe 公开验收入）、Profound Prompt Volumes（反推 ChatGPT 提问词）。**API 取数**：GSC 用 Google Apps Script 定时 `getGSCDataViaRest`（建议凌晨 1–2 点，id=873）；Google Ads API / SEO Agent `seo.web.cafe/api/` 的 DR、KD 接口（老 KD 接口保留，id=232）；关键词搜索量接口成本高，哥飞 9/4 起仅此一项充值 $1350（id=237）。

**建站技术栈**：Next.js/Nuxt（SSR 利于 SEO）；Vercel（部署快但**带宽/资源计费对 PSEO 站极不友好**，id=1066）；Cloudflare Pages/R2 免费图床/D1（实时排行榜易超免费阈值，id=221）/Turnstile 免费人机检测/邮件转发免费域名邮箱（WAF 规则集纯静态站别开，误伤，id=152）；Supabase 登录+库、Stripe 支付、Resend 邮件、Upstash 限流、Zoho Mail（$1/用户/月，比 Google Workspace 便宜，id=933）；VS Code+Claude Code/Cursor/Codex/Astra/Playwright MCP；Replicate/Huggingface/fal/kie/seeapi/302.ai 等模型 API（避开需冷启动的模型，id=232）。

**收款**：Stripe（付费成功率最高、欧美公信力强、自动带出已存卡号，id=232；一个身份一个账号多商户）、PayPal.cn（国内主体，可关联美国公司显示名，便于「说上话」解封，id=216）、Waffo（个人可开、无需公司、MOR 模式，国内个人走 waffo.ai 提现支付宝，新手推荐先用，id=226、212）、Creem（2026-09 被吐槽拒审/爱退款，建议绕开）、Wise（开英国 Stripe）、z-pay、Escrow.com（卖站担保，id=219）。

**广告**：Google Ads（只投搜索网络、点击出价冷启动再转转化出价、国家按后台出单国挑、必设最高 CPC，id=742/745）、Bing Ads（id=235）、AdSense（正规、几乎不扣量，id=1048）、Adsterra/MoneTag（好过审但广告野，需后台关违规类目，id=1048）。

## 四、新词比赛／上站行动：反复验证的共同打法

1. **先上站，上线比天大**：不打磨、不多想，看到新词几天一周内直接上，失败成本就是一个域名钱（id=204、151、197、1091）。
2. **像素级模仿**：新手完全按教程手动做，卡壳马上请教，先练词感——至少看 100 个网站、100 个关键词、1000 个网页（id=813、211、204）。
3. **多上站、雨露均沾**：不押注单词、不因一个词没起来自我怀疑；把上站练成肌肉记忆，每站只优化一次模板（id=140、910、239）。
4. **全链路复盘**：记下每站的找词方法、耗时、内页安排、外链节奏、数据结果；只上站不管后续等于无效上站（id=813）。
5. **GSC 三板斧**：提交 URL+sitemap → 24–48h 看是否出词 → 不出词逐项排查文案长度、TDH 覆盖、词密度、是否前端渲染（id=28、848）。
6. **出词后抄作业加外链**：搜竞品 → Ahrefs/Semrush 导外链取并集 → 越多家都有的越先加；新站权重为 0 时「质量再差也比没有强」（id=28）。
7. **内页做精品不赶量**：10 个精品工具页远胜 100 个水文，每页给增量信息、留住用户不返回 SERP（id=932）。
8. **接支付+埋点漏斗**：先接好支付再谈优化，埋点看用户卡在哪一步（id=211 王一晚 9 单）；免费额度一两次、每天限 API 成本 $10（id=215、224）。
9. **定价做 A/B**：一半流量 A 一半 B；9.9 单卖旁挂 19.9 三视频套餐；一次性付费优先于订阅（id=211、222、212）。
10. **ChatGPT/GEO 顺带吃**：反推用户会问什么、观察 AI 抓哪些页面、写能完整解决任务的工具页；用 http referer+自建库双记来源（id=216、212）。节奏 40% 找词、20% 开发、40% 宣传搞外链，站没起来前找词占 80%（id=340、204）。
