# 02 找词 / 热词获取：渠道清单、系统化流程与整理规范

> 资料范围：B_sourcing（Top45 摘录）、core_1_finding（13 篇核心找词长文）、core_4_tools（9 篇工具长文）。所有数字、阈值、工具名均保留自原文，标注 `[id=数字]`，文末附「来源索引（id ↔ 文档标题）」。

## 0. 底层原则与训练量

- 关键词＝需求；聚焦「出海 / AI / 工具站」，工具站靠付费变现，收入高于纯广告 [id=306《再聊需求挖掘：六种挖掘需求方法详解》]。
- 核心原则：**新手要找新词，或找竞争度低的老词**；新词竞争几乎空白，可「上线即排名」[id=792《哥飞.ai 教你怎么挖掘出第一个关键词》]。
- 时间分配：**40% 挖掘需求 / 20% 开发 / 40% 宣传推广搞外链**；「2 小时找词对应半小时上站」，若一站要两三天，花一周找词都不为过 [id=804《漫游找词SOP》][id=340]。
- 训练量：每天看 **100 个关键词、1000 个网站**（良辰美一天看几千页）；新人「至少看 100 个网站、100 个关键词、1000 个网页」[id=63][id=211]；「没看 100 个 AI 需求词、1000 个 AI 工具站、做 10 个站以上」不算入门 [id=878]。判断力只能在重复中形成，无捷径可跳过 [id=811]。

## 1. 找词渠道清单（渠道 → 操作路径 → 词型 → 阶段 → 局限/坑）

### A. 谷歌自家（数据最准，用来「挤水」与定口径）

**A1 Google Ads 关键词规划师** [id=77][id=1037][id=256][id=69][id=753]
- 路径：广告后台→工具→规划→关键字规划工具；①「发现新关键词」输入 `ai photo`、选英语、**删除所有位置**→基于语义给出 `ai image` 等未知词 [id=1037]；②「获取搜索量和预测数据」一行一个粘贴词表→**清除默认地址**→得搜索量与单次点击出价区间 [id=77][id=256]。
- 词型：任意种子的语义扩展词、精确搜索量、CPC 商业价值。阶段：全流程「挤水 / 校准」终点。
- 坑：**账号需花过广告费才显示详细数据，否则只有区间** [id=69]；`GPTs` 被合并进 `GPT`（月 2490 万），不能直接查 [id=69]；Ads 把同义词归一类给相同搜索量，需借 Trends 加双引号区分谁更大 [id=256]；数据可能并入别的词造成虚高（`ai photo editor` 9 月 55 万→10 月 150 万）[id=69]；不相关词（如 `download video instagram`）手动移除；下载选「方案历史指标」CSV [id=1037]。
- **MCC / ADS API 拿数据**：注册 Google Ads 经理账号(MCC)→API 中心创建**开发者令牌**（**测试账号权限即够做关键词规划与搜索量预测**）→Python 调 API 批量拿「最权威的谷歌搜索量」；需配 GSC 账号 + OAuth2 [id=753《MCC 注册并获取 ADS API Token 拿关键词搜索量》][id=804]。

**A2 Google Trends 谷歌趋势（6 大用法）** [id=53《谷歌趋势 6 大核心用法》]
- 六大用法：①查热度(≈搜索量) ②判断是否新词 ③看一段时间趋势 ④按国家/地区热度 ⑤看某分类下热门词 ⑥找新词 [id=53]。
- 反推搜索量：「已知词对比法」——直接值都是**相对值 0–100**（时段内最高=100）[id=53]；锚点 `GPTs≈5000+/天`、`GPT` 月 2490 万/日均 83 万 [id=69][id=53]；`mistral ai` 是 GPTs 3 倍≈1.5 万/天 [id=53]；`AI Photo Editor` 是 GPTs 3 倍≈1.8 万/天、月 56 万，Ads 验证 9 月 55 万 [id=69]；`Ghibli` 于 3-30 当天≈78 万，此前 45 万/月（日均 1.5 万），涨 52 倍 [id=53]。
- 判断新词：拉长到 **30 天 / 90 天 / 12 个月 / 5 年**，看曲线「从哪天开始有」即出现日；`ChatGPT` 2022-11-30、`GPT-4o` 相关词 5-13、`chat gpt ghibli` 3-26 [id=300][id=739][id=53]；**出现日在 30 天内最佳，一年内都可算新词，越近优化难度越低** [id=300][id=53]。
- 找新词：任意词输入→选全球 / 最近 7 天→右下角「相关查询」看「上升」可取**最多 25 个**词→对飙升词点「探索」拉长到一年验证 [id=53][id=22]；`TTS`→`ChatTTS` 及 Typo 词 `ChaTTS`；`AI Music`(90 天)→`udio`→`suno` [id=300]；不输关键词按分类看飙升词 [id=53]；「每日搜索趋势」盯 24–48h 飙升 [id=792]；`Google Trends API` 可自动化（直接搜该词找接入文档）[id=300]。
- 坑：`Ghibli` 看似新词实为老词（吉卜力已有大量网页占位）；**区域热度是人均相对值，不能当搜索量排序** [id=53]；RPA/爬虫采集易被人机验证拦截 [id=804]。辅助：良辰美「喂饭式 GoogleTrends 词根表」、插件 TrendsBar / Trends Radar [id=1037]；SiteData 可在 Google 搜索页内嵌 Trends 模块、自定义对比词与时间范围 [id=978]。

**A3 谷歌下拉 / 相关搜索 / PAA** [id=77][id=256][id=306]
- 路径：谷歌搜 `ai photo` 后**加空格**看自动补全；可不断加词得到更细分长尾；「People also search for（相关搜索）」再取一批；YouTube/TikTok 等任何带搜索框的平台都有下拉 [id=77][id=1037]。
- 词型：真实高频长尾、同义表达（`photo/image/picture/pic/img` 尽量全覆盖）[id=256]。阶段：冷启动收集。
- 坑：**下拉词看不到搜索量**，先收集再校准 [id=77]；用飞书在线表格保存 [id=256]；提效工具 `niemingxing/search-recommendations`、`searchsuggest.tips`、`keywordtool.io`、`searchsug-extractor.com` [id=77]。

### B. 第三方 SEO 工具（找词 + 反查 + 竞争度）

**B1 Semrush** [id=306][id=1037]
- 路径：Keyword Magic Tool 输入词根→「查看全部关键词」→筛 **搜索量≥30000/月（日均 1000）、KD≤60（最好 0~29）、CPC≥$0.01**，按搜索量 / KD / CPC 三种排序交替看；左侧「关键词群组」选 AI 得全带 AI+Generator 的词；「年趋势」列可视化看是否新词 [id=306][id=1037]。
- 工具对比：Semrush 看某网址关键词**一次只能看一个国家、还要分 PC/移动端切换** [id=77][id=256]；免费版 Ahrefs Free Keyword Generator（`ahrefs.com/keyword-generator`，选谷歌+美国）默认给大词、KD 高，一般不用 [id=306][id=732]。
- 阶段：种子→词库主力。坑/阈值变体：袁锐钦 2026-04 更激进——**新手只看 KD 0–29、CPC≥$0.1**，用 KDRoi 排序 [id=830][id=792]；哥飞另建议「KD 不要限制太低，建议 21~49」[id=1037]；导出 CSV 换下一词根，每词根产几十到上百词 [id=792]。

**B2 Ahrefs** [id=23][id=47][id=97]
- 路径：免费 Website Traffic Checker（`ahrefs.com/traffic-checker`）免登录看站流量/核心词/大流量页；Keyword Difficulty（`ahrefs.com/keyword-difficulty`）查 KD 与进前 10 所需外链域名数 [id=306][id=23]。
- 阈值：**所需外链网站数 <100 可尝试** [id=97][id=733]；`poxer` 难度 0 [id=97]；29 美元/月版本功能齐全 [id=47]。竞品反查看 Top Pages、新增关键词、流量增长页、Content Gap、外链来源 [id=164]。

**B3 Similarweb** [id=97][id=1037][id=164]
- 路径：输入域名看流量/来源/地域/相似网站（免登录）；「关键词研究→着陆页」输入网址看该页拿流量的词；「自然落地页」勾选**「新发现 / 新页面」**筛最近才起量的页 [id=1037]；关键词生成器拓展 [id=77]；筛「新点击量 + CPC>0.01 + 体量>30000 + Regular Search」按点击量排序、重点 KD<60 [id=164]。单位 **M=100 万**（8.8M=880 万、138.8M=1.388 亿）[id=97]。
- 免费导出：导出要积分→装 Chrome 插件 **Table Extractor** 导出 json/markdown/csv→丢给 Claude Code 调 agents 分析；油猴脚本 / xpath 都不好用、无法一键导出 [id=764]。
- 坑：Similarweb 摸**全渠道流量**、Ahrefs 摸 **SEO 流量**、插件又是另一口径，**不能相减、不能只看一家**；第三方都是**估算值**，不用来看新站 [id=797][id=930]；semrush/similarweb/ahrefs「各有用法、没有大一统」[id=218]。

**B4 GSC 现有数据反查** [id=930][id=340][id=211]
- 路径：上站后看 GSC 已冒出的词→顺手让 AI 补内页 [id=1100]；「已编入索引的网页数」=内页数，少则把每个内页做精 [id=932]。
- 阈值：**上线 48 小时即可看出词数据**；做好站内优化+一定外链，**1–2 周应出词且有曝光点击**；没出词先回头查站内优化/外链质量数量，别继续砸钱 [id=930]。坑：GSC 与第三方口径不同 [id=930]。

**B5 竞品站 / 大站反查** [id=306][id=63][id=1037]
- 路径：谷歌搜词→点开前 3 名 SEO 好的站→Similarweb/Semrush/Ahrefs 看「流量来源关键词」与「能拿流量的页」→特别关注**大站仅靠一个内页就拿走绝大部分流量的词**，专门做站用首页打它内页 [id=306]。
- 案例：Canva 关键词第 1 `color wheel`、第 4 `qr code generator` [id=306]；`elgoog.im`（2011 上线、月访 150 万、72% 来自谷歌、峰值 213 万）由 `maker` 词根→`barrel roll maker` 找到，第 2 名 `tryhardguides.com` 月访 272 万 [id=63][id=291]；其流量词 `Fisch codes` 是新词（24 年 10 月初出现，11 月 122 万/日均 4 万，高峰 GPTs 6 倍≈3 万多，回落后日均 8000）[id=63][id=70]。坑：排除品牌词 [id=306]。

**B6 大站新页面 / sitemap 监控** [id=1037][id=218][id=1064]
- 路径：Similarweb「自然落地页」看「新页面」（上月才有流量）→新需求竞争小；`Character.ai`（月访 1.75 亿）第 6 页 AI 虚拟女友、第 9 页角色扮演，`ai hoshino` 难度 2、只需 3 个外链 [id=1037]；`Gumroad` 月访 2445 万、人均 4 页、停留近 3 分钟 [id=1037]；Pinterest 某内页（Good Morning Quotes）月 118 万，衍生 App 月入 12 万+ 美金 [id=1037]。
- sitemap：观察大站 sitemap 变化发现其追新词/长尾 [id=1037]；用 **changedetection.io** 盯竞品 sitemap、抓 `sitemap.xml` diff [id=218][id=1064][id=922]。

**B7 站内出站域名 / 外链反查** [id=1037][id=830][id=298]
- 路径：Semrush 查 `vc.ru`/`pikabu.ru` 的「出站域名」按首次发现时间从近到远→whois 查注册时间→Similarweb 查流量→Archive.org 看历史页→按「7 月新注册+谷歌已收录+流量>X」筛正在推广的新产品 [id=1037]；竞品 Backlinks→Referring Domains 看它链接了谁 [id=830]；博客评论外链列表（谷歌搜 `blog commenting sites list`）→`site:` 域名找相近文章发外链 [id=298]。逻辑：会去发外链的站都有利可图 [id=1037]。

**B8 广告投放中的产品** [id=306][id=1037][id=830][id=978]
- 路径：Similarweb「关键词浏览工具→竞争对手→付费流量」看哪些站在长期投广告；别人长期砸钱=能赚钱的需求 [id=306][id=1037]。
- 案例：`qr-code-generator.com` 月访 660 万、近 12 月花 **730 万美元**广告费（790 万访问/730 万收入≈1 访问 1 美元；660 万免费流量×$0.1≈66 万美元/月）；买量第一 `qrfy.com` 花 **1530 万美元** [id=306][id=792]。
- 支付网关反查：Stripe / `checkout.stripe.com` 入站域名找已接入支付、正在赚钱的站（近一年注册、持续赚钱）[id=830][id=218]；看支付页域名（`pay.域名.com` / `checkout.stripe.com`）访问量估订单（支付成功率 10%–50%）[id=1037]。辅助：SiteData 在 SERP 直接显示网站**最近四周** Google 搜索广告投放条数 [id=978]；「上线后收录慢，投一点 Google Ads 就被收录」[id=878]。

### C. 托管子域名 / 新产品雷达

**C1 vercel.app / github.io / pages.dev** [id=31][id=1037][id=911][id=1100][id=211]
- 路径：Similarweb 查 `vercel.app`→「自然落地页」选最近 12 个月（或 1 个月）勾选「新发现」→看排名靠前子域名承接的词→取前两个去 Trends 验是否新词 [id=1037][id=31]；`new.web.cafe/hosted` 查 vercel.app、github.io、pages.dev 子域名流量，`new.web.cafe/launches` 抓 HN 等平台 **592 个新站** [id=211]；`site:vercel.app` + 工具目录 + GitHub README + Product Hunt + Reddit 观察，archive.org 看快照 [id=31]。
- 词型：最新上线、还没买域名（个人 / side project / vibe coding）的产品需求词，多不懂 SEO、是「软柿子」[id=31]；`huggingface.co` 着陆页 28 天内页找词（`italian brainrot`）[id=911]；一个 vercel 老词站只有单首页 iframe、4 月 24k 流量却排谷歌第一 [id=911]。
- 阶段：新词发现（最上游，滞后最小）。坑：**不是会被挖光的金矿，而是不断生长的金矿** [id=31]；semrush 看不到子域名 / 改版需更贵套餐 [id=31]；需去重、去垃圾、用 API 判流量后人工复核 [id=1064]。

### D. 社媒 / 内容平台（新词源头）

- 路径与信号：**X/Twitter**（`#SaaS` `#IndieHackers` `#BuildInPublic`、Build in Public 开发者月收入、`Strata Qwen` 9-26 由推特扩散）、**Reddit**（r/SaaS、`[竞品] sucks/overpriced/alternative`、评论区反复出现的问题）、**TikTok**（`tiktok.com/discover/关键词`、评论区「哪里可以用 / 有没有网页版 / 叫什么工具」）、**YouTube**（播放快增的新游戏 / AI 玩法 / 教程，下载游戏视频字幕交 AI 整理成结构化页）、**Instagram / Facebook / Threads** [id=164][id=830][id=218][id=922][id=160]。
- 排序：言午木杉「社媒采集信号→指标衡量传播度→关键词工具旁路印证」；零壹排序 **X > Ins > Reddit** [id=218]。
- 词型：事件 / 梗 / 新玩法 / 组合词（`Strata Qwen`、`SBTI`、`niko strata`）、传播中冒出的更简洁说法与 Typo [id=55][id=300]。阶段：最上游（比 Trends 更早，但赌性大）。
- 坑：**越早赌性越大**；哥飞新词监控看 Trends **7 天热度**，一个词最晚 7 天后才被发现 [id=55]；社媒千人千面，从社媒找比从词根找竞争小（小张 7 月新词全期只有他一人注册域名）[id=160]；热点窗口短，看到就上，「损失最多一年域名费」[id=55][id=1083]。

### F. 词根 / 51 财富密码 / 漫游 / AI 提问

- **51 个工具类词根**：Generator / Converter / Calculator / Editor / Maker / Checker / Planner / Assistant / Simulator / Scraper / Comparator 等（如 Password Generator、Mortgage Calculator、Grammar Checker）[id=830][id=1037]；社群扩充版 **98 个词根+搜索意图+建站机会**、Truman 积累 **100+ 词根**（51 个来自哥飞，其余自拓）[id=792][id=1052]。
- 词根入库标准：**通用常见且流量大**，丢进 Trends 与 GPTs 比，**≥GPTs 1.5–2 倍**才收；每天点开看相关查询有无飙升 [id=1052]。
- **词根漫游法**：已知根词（AI）→Trends 看相关推荐 / 主题→点开可做工具的相关词→关注「搜索量上升」→把新词当新根词调小时间再扩；根词列表以 **7 天或 30 天**为周期查询，能扩出新词则留、不能则删；根词要满足通用性 [id=22][id=1037]。51 词根放进 Trends 也能找新词；「用户记不住产品名就搜功能名」，可直接做功能名产品 [id=300]。
- 案例：`maker`→`barrel roll maker`→`elgoog.im`→`Fisch codes` [id=63]；Truman 8w 流量站找词只花 10 分钟，但词根库积累 **2 个月 / 每天 4–5 小时** [id=1052]。漫游量级：Maker 词根有 **23 个**上升词，`51×23=1173`，再延伸一次 `1173×23=26979`，还要 ×3 看 7/30/12 月曲线 [id=811]。
- **ChatGPT / AI 提问**：词根 + Google 联想词 + ChatGPT 筛选（`"xxx game"` / `"xxx guide"`）[id=829][id=878]；让 AI 解析词来源 / 搜索意图 / 为何火 [id=1072][id=1091]；Ads 结果转 markdown（`tableconvert.com`）粘给 Claude 做需求分析并「规划 SEO 友好网站结构、要做哪些页面」[id=1037]；新词先问 GPT 能不能做（但别全信，见 id=140 教训）[id=172]。

### G. 跨语言 / 多语言单独找词

- 逻辑（来源 [id=147][id=160]）：正面战场打不过原生站（如西语），用**多语言内页侧面切入**吃其他地区流量；小张用**子目录模式**多语言、加分享按钮 [id=147][id=160]。中文需求词可从 V2EX 单独提取 [id=164]。
- 坑：减少没必要的多语言内页（李才双建议）、做好 noindex 取舍；收录≠完整抓取，脚本加载失败会让 React 清空 title / 元数据 [id=147]。

## 2. 系统化流程（从 0 到「词找站、站找词」闭环）

**阶段一：从 0 到第一个关键词**
1. 备工具：谷歌搜索、谷歌趋势、谷歌广告、Similarweb、Semrush、Ahrefs（免费功能够用，付费可淘宝共享账号）[id=306][id=97]。
2. 选起点：从 51 个词根池挑一个（如 Generator），或从感兴趣领域单词（`cat`/`dog`/`poe2`/`genshin`/`Disney`/`editor`/`table`）[id=792][id=804]。
3. Semrush Keyword Magic 设筛：搜索量≥30000/月、KD≤60（或 0–29）、CPC>$0.01（激进版≥$0.1）；排除 NSFW（`sex`）、导航意图、`near me` 本地词；导 CSV [id=306][id=830][id=804][id=792]。
4. 三种排序交替：搜索量↓找大需求 / KD↑找易打 / CPC↓找离钱近 [id=792]。
5. 逐个 Trends 判新词（12 个月曲线）、Ads 校准真实量、算 KGR / KDRoi 双公式 [id=792]。
6. 谷歌搜前 10 看 SERP：首页/内页占比、DA 80+ 大站、页面质量、广告位、Featured Snippet / PAA 占位 [id=23][id=792][id=797]。
7. 确认意图与商业价值→注册关键词匹配域名→AI 数小时内极速上站→**单域名、单站、单关键词** [id=792]。

**阶段二：从种子词拓到词库**
8. 对种子词跑 8 渠道扩词：谷歌下拉、相关搜索 / PAA、Trends 相关查询（25 个）、Ahrefs/Semrush/Similarweb 关键词生成器、Ads 发现新关键词、各平台搜索框、YouTube/TikTok 下拉 [id=77][id=256]。
9. 表达全覆盖（`photo/image/picture/pic/img`），不断加空格取更长尾 [id=256]。
10. 合并去重→用「获取搜索量和预测数据」批量拿量→**两家第三方都不信、以谷歌为准**、Trends 加双引号比大小 [id=77][id=256]。
11. 三种排序 + 年趋势列 + KDRoi 列排序，剔除陷阱词：**季节词（母亲节）、谷歌直达词、搜索量特别大但竞争奇低** [id=1037][id=97][id=804]。

**阶段三：从词到站**
12. 判断「单独注册域名」还是「做内页」：搜索量小但竞争大→放弃；有一定搜索量即使竞争大也可做；已有站且用户匹配→做内页即可，不为拿排名 [id=23][id=47]。
13. 单点突破：排名靠前多为内页→直接拿关键词注册域名专门做站（新词老词皆可，新词更快）[id=1037]；已被关键词域名霸占的大需求用品牌词策略（`TinyPNG.com` / `imagecompressor.com`）[id=1037]；关键词注册域名后谷歌出 sitelinks 即「无敌」[id=298]。
14. 预期收益倒推：如目标 1000 美元、客单 10 美元→需 100 付费用户→注册率 50% / 付费率 0.5%→需月 **4 万流量**，据此按热度选词 [id=181]。

**阶段四：从站反查更多词（「词找站、站找词」闭环）**
15. 谷歌搜词→点前 3 名 SEO 好站→Similarweb/Semrush/Ahrefs 挖其流量来源词与 Top Pages→特别抄「大站单内页拿流量」的词 [id=306]。
16. 用新词回谷歌再找 3 个站，反复循环——「在流量的海洋里冲浪」[id=306][id=792]；赫兹归纳为 **词根找词 / 站找词 / 站找站** 核心循环，用得越多「网感」越强 [id=830]。
17. 关联词圈扩一圈：同义不同说法→上下游功能词→Similar Sites 竞品站再反推 [id=797]。
18. 上站后 GSC 反查已出词→让 AI 补内页、把上过站的主关键词加入词根找相关搜索词持续扩内页 [id=1100][id=172]。
19. 「网站→词→更多词→更多网站」循环即打开新世界 [id=300][id=1037]。

> 新词传播全链路时序（越靠后越滞后）：源头→小圈子→社媒→无数小圈子→社媒→谷歌趋势→大站内页→新站主页→更多站内页→更多新站→Similarweb/Semrush/Ads 上月数据→「有站拿大流量」被小圈子传播→自媒体分析→更多群 [id=55][id=218]。

## 3. 新词 vs 老词

- **定义**：过去 **12 个月内才开始出现显著搜索量**；30 天内最佳；出现时间越近优化难度越低 [id=792][id=300]。判定用 Trends 30/90 天/12 月/5 年曲线找「开始有曲线那天」[id=300]；**「一个 KD 50 的半年内新词，比 KD 30 的一年前老词更容易拿排名」** [id=1037]。
- **老词**：长期稳定（pdf 编辑 / 转换 / 压缩），前排被老站霸占，新站短期难拿排名 [id=306]。
- **验证方法**：
  - 新词：Trends 曲线 + Ads 里「之前没数据＝新词」[id=53]；查 `query.domains` 域名注册情况（com/ai/net 是否被注册、上线没）[id=1083][id=63]；`intitle`/`allintitle` 看供应量（如 intitle 只有 **124**、几百上千即轻）[id=1100][id=181]；SERP 里是否多为内页 / 无正经站 [id=1083]。
  - 老词：看首页是否有新站首页、其排名 / 外链数 / 月访问量、关键词搜索量 [id=878]；KD、前 10 外链、是否需完全免费策略（`ai face swap` 打败第一名需几百上千外链且完全免费；其 23 下半年新词、日搜 GPTs 6 倍、去年 12 月 55 万 / 日均 1.8 万、KD 60 需 129 域名外链、第一名 304 域名外链）[id=23]。
- **何时抢新词**：竞争空白、上线即排名、正反馈快（新词当天出词，老词不加外链要 2 周才出词）[id=181]；新词还没 KD 数据、不用看 KD [id=211]；看到就上，「上对一次赚回十个百个域名钱」[id=55][id=1091]；但热度词命短（SBTI 后日收入 $150→$80→$30→$20）[id=1083]。
- **何时用长尾反向吃老词主词**：老需求太大时用「保小图大——小词图谋大词」[id=1037]；用内页承接主词的品类词 / 长尾再跳首页（关键词簇：一组词对应一个需求一个页面）[id=181]；单点突破用首页打别人内页「以弱胜强、以新胜强」[id=792]。
- **提前布局 / 等搜索量起来（老站内页验证法）**：犹豫是否注册域名时，先在**老站上内页**（越早上内页越易拿排名），观察能拿到搜索流量还是 ChatGPT 推荐流量、有无付费转化，再决定独立建站 [id=55][id=76]。案例：老站内页带来十几笔付费、平均订单 `795/14=56 刀` 与 `91 刀`、首次使用到付费约 **6 分钟**；新站首日 **600 UV / 1400 访问 / 255 注册 / 17 单 / 221 美金**，其中 ChatGPT 渠道 282 访客 / 172 注册（注册率 **61%**）/ 付费率 **6.4%** [id=76]；ChatGPT 倾向推荐「首页能完美匹配需求」的站，故可拿词注册域名抢推荐流量 [id=76]。
- **坑**：新词太晚进场=量级与 Trends 不匹配 [id=1091]；游戏词出现 **>30 天**且竞品域名 **>20 天**果断放弃 [id=922]；趋势下降要查清原因（市场萎缩 vs 被系统内置替代，如「在线 PDF 压缩」被 Chrome/macOS 内置）[id=1007]；蹭品牌词会收 DMCA，别在 Cloudflare 注册域名 [id=172]；`Password Generator` 月搜几十万但 KD 90+、首页全是 DA 80+ 十年老站，别被大词虚高搜索量骗 [id=792]。

## 4. 关键词收集后的整理规范

- **收集与保存**：用飞书在线表格（哥飞自用），下拉词「看不到量也先收」[id=77][id=256]；Ads 结果选「方案历史指标」下载 CSV→删不相关词、删多余列、按搜索量↓排序→`tableconvert.com` 转 markdown→粘 Claude 分析 [id=1037]；Similarweb 用 Table Extractor 导 json/markdown/csv [id=764]。
- **建议表格字段**（由各文操作项归并）：关键词 / 来源渠道 / 词根 / 搜索意图（工具页·教程问答·导航·商品）/ 月搜索量(Ads 为准) / 日均 / CPC / KD / 进前 10 所需外链域名数 / `intitle`·`allintitle` 供应量 / **KGR = intitle 结果数 ÷ 月搜索量**（案例：intitle 3440、月搜 20 万、KD 7 → 好机会）[id=792] / **KDRoi = Volume × CPC ÷ KD**（A：5000×$2÷25=**400** vs B：50000×$0.1÷80=**62.5**，A 性价比高 6 倍）[id=792][id=830] / 年趋势·出现日期(新词?) / SERP 前 10 首页-内页数 / 有无 DA 80+ 头部大站 / 国家地区 / 多语言变体 / 域名注册情况(query.domains) / **来源 `[id=数字 + 标题]`** / 决策(做·内页·弃)。
- **对齐维度**（id=77/id=256 主题）：跨平台前必须统一同一口径——**同一国家、同一 PC/移动端、同一时间窗、同一精确/广泛匹配**；Semrush 一次只一国且要分 PC/移动端 [id=77][id=256]；同义词 / 词序用 Trends **加双引号**校准（`2025 calendar` vs `calendar 2025`：不加引号谷歌认为热度一样，加引号才看出哪种说法用得多）[id=256]。
- **去重**：多来源合并后先去重得唯一词表 [id=1037]；Ads 把同义词归类给相同搜索量，需人工拆 [id=256]；自动找词流程每天「去重、去垃圾、用相关 API 判谷歌流量、人工复核」[id=1064]。
- **跨平台数据口径（关键）**：**Similarweb / Semrush 都是第三方估算，哥飞「两家都不信，信谷歌」**——Trends 比大小、Ads 关键词规划工具看绝对量且「最准确，因为 Similarweb/Semrush 的量也来自这里」[id=77][id=256][id=1037]；Ahrefs=SEO 流量、Similarweb=全渠道流量、插件=另一口径，**不能相减、绝对值不能反推收入**，要看收款截图 / 付费用户数等硬证据 [id=797][id=930]；判「真 SEO 词矿 vs 投流站」用 **流量 ÷ 词数**：流量高+词多=真词矿，流量高+词少=投流站（无词可抄）[id=797]。
- **建词库**：建站之初用 semrush/ahrefs 筛词库→导出来归类→布局到各页面；上线后看词库增长趋势、前 20 名词库、据首页前 5 名做 on-page 优化 [id=340]；词根库当资产维护（7/30 天周期刷新、能扩新词则留）、外链库同理（Truman 积累 **70+ 条**外链站点、100+ 词根 docx，全从竞对网站用 semrush/ahrefs backlink checker 抄作业）[id=22][id=1052]；可把 GA/GSC 导 CSV 交 AI 分析迭代 [id=1072]。
